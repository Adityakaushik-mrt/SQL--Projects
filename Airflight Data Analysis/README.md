## ✈️ Airline Flight & Booking Analysis Using SQL

This project focuses on analyzing an airline flight and booking dataset using SQL to answer real-world business and analytical questions.

The analysis covers **flight fares, bookings, revenue, passenger behavior, cancellations, destination airports, flight rankings, and monthly revenue growth**.

### 🎯 Project Objective

The main objective of this project is to strengthen SQL analytical skills by solving practical business problems using SQL queries, including aggregation, joins, Common Table Expressions (CTEs), window functions, ranking, date-based analysis, and revenue calculations.

### 🔍 Key Analysis

* Find and analyze flight fares
* Calculate total bookings by seat class
* Calculate revenue by flight
* Identify passengers with more than three bookings
* Find the most popular destination airport
* Calculate overall cancellation rate
* Identify top flights based on booking revenue
* Rank flights based on revenue
* Find passengers whose latest booking was cancelled
* Calculate monthly booking revenue
* Calculate month-over-month revenue growth

### 📈 Analytical Areas

**Flight Performance:** Fare and revenue analysis by flight.

**Booking Analysis:** Booking volume by seat class and passenger booking behavior.

**Revenue Analysis:** Flight-level and monthly revenue analysis.

**Cancellation Analysis:** Cancellation rate and cancelled booking behavior.

**Airport Analysis:** Destination airport popularity and flight activity.

**Time-Series Analysis:** Monthly revenue and MoM growth.
